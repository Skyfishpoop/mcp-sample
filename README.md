# mcp-sample

## 連載構成

| 回 | テーマ | ディレクトリ |
|---|---|---|
| Part 1 | 最小構成でMCPサーバーを動かす | [part1/](part1/) |
| Part 2 | 設計判断3つ(言語・通信方式・スコープ) | (準備中) |
| Part 3 | 詰まりポイント集 | (準備中) |

各回のコードはディレクトリで分離されています。記事を読みながら手元で動かす場合は、対応するディレクトリ配下の README に従ってください。
